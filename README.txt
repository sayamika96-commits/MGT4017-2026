# PalateSatisfy website prototype

## Files
- `index.html` — page structure and content
- `style.css` — colours, layout, responsive styling and component design
- `script.js` — mobile navigation, category selection and demo contact form behaviour

## Run locally
1. Extract this ZIP folder.
2. Keep all three files in the same folder.
3. Double-click `index.html` or open it in a web browser.

This is a front-end prototype. The category buttons and contact form demonstrate interactions only; they are not connected to a live shop, account system, payment service or email database.
